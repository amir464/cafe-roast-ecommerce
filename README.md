# Cafe Roast

Cafe Roast is a Persian RTL coffee-shop ecommerce frontend built with React, TypeScript, and Vite. It uses local data and browser storage for a self-contained demo experience.

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
- React Hook Form
- Zod
- Lucide React
- LocalStorage
- Docker
- Nginx

## Features

- Persian RTL storefront and responsive design
- Product catalog and product details
- Cart and wishlist
- Demo authentication
- User and admin dashboards
- Product and order management
- Reports and charts
- Light and dark themes

## Local Development

```bash
npm install

```

## Production Build

```bash
npm run build
```

## Docker

```bash
docker compose up --build
```

Open [http://localhost:8080](http://localhost:8080), then stop the application with:

```bash
docker compose down
```
